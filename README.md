## The letter

**Z** — for **zombie**: a day spent shambling through on zero sleep.

Every word a reader could hear behind Z — zombie, zero sleep, zonked, zzz — is vivid, funny, and true, so there is no weak reading of this letter.

## How it works

`main.ts` (Node 22) writes exactly one character, `Z`, to `/output/entry.txt` — nothing else: no word, no gloss, no punctuation, no trailing newline.

```sh
node main.ts
cat /output/entry.txt  # Z
```
